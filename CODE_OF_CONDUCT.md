# 🌱 Code of Conduct

**Developed by Syed Muhammad Tayyab**

</div>

## Our pledge
We want this project to be a friendly, harassment-free space for everyone, regardless of background, identity, experience level or opinion.

## ✅ Expected behaviour
- Be respectful and patient, especially with beginners.
- Give and accept constructive feedback gracefully.
- Focus on what is best for the project and the community.

## 🚫 Unacceptable behaviour
- Insults, harassment, or discriminatory language.
- Publishing others' private information.
- Trolling or deliberately derailing discussions.

## 📣 Enforcement
Report problems to the maintainer via [GitHub](https://github.com/Syed-Muhammad-Tayyab). Maintainers may remove comments, commits or contributors that violate this code.

*Adapted from the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).*
